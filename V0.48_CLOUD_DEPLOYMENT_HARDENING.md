# SYLVIA v0.48 Beta — Cloud Deployment Hardening

## Scope
- Security headers and reduced framework fingerprinting.
- Hosted base URL must use HTTPS.
- MQTT bridge supports TLS and optional CA-file pinning.
- Bridge forwarding requests have a bounded timeout.
- Docker images run as a non-root user.
- Web container exposes a healthcheck for orchestrators.
- Environment variables document the hosted MQTT/TLS contract.

## Hosted requirements
- PostgreSQL with `DATABASE_URL`.
- MQTT broker reachable by the bridge.
- `SYLVIA_BRIDGE_TOKEN` set to a long random secret.
- `SYLVIA_PUBLIC_BASE_URL` set to the HTTPS beta-site origin.
- `SYLVIA_MQTT_TLS=true` for production MQTT.
- Supply a CA file when the broker uses a private CA.

## v0.47 → v0.48
The hosted architecture from v0.47 is retained; v0.48 hardens its deployment boundary before hardware end-to-end testing.
