# SYLVIA v1.6 database mode

Set `DATABASE_URL`, install dependencies, then run `npm run db:migrate`.

The UI keeps local demo mode available when no database is configured. The server exposes `GET /api/v1/db-status` so deployment checks can confirm whether PostgreSQL is configured and reachable.

The first migrations create users, projects, project memberships, devices, datastreams, telemetry events and useful indexes.
