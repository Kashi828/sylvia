# SYLVIA v0.27 Beta — Bulk Command Dispatch

v0.27 connects fleet group operations to the existing MQTT transport.

## Dispatch

`POST /api/v1/groups/:id/dispatch`

Headers:
- `Authorization: Bearer <device token>`
- `Idempotency-Key: <stable operation id>` (optional)

Body:

```json
{
  "command": "relay_on",
  "payload": {
    "value": true
  }
}
```

Each device receives an operation key:

`<operationId>:<deviceId>`

## Results

Each target is independently marked:
- `queued`
- `sent`
- `failed`
- `rejected`

The dispatcher uses MQTT QoS 1 through the existing transport layer.

## Important beta limitation

The current registry and operation store are in-process. Production v1.0
should persist operations and idempotency keys and implement durable delivery
receipts before claiming exactly-once semantics.
