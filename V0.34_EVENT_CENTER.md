# SYLVIA v0.34 Beta — Event Center

The Event Center unifies telemetry alert events and webhook delivery activity into one operational timeline.

## UI
- Event Center workspace
- Active alert, alert event, webhook delivery and failed delivery counters
- Filter by event type and severity
- Newest-first timeline
- Automatic refresh every 5 seconds
- Delivery HTTP status and failure details

## Data sources
The beta UI consumes the existing alert APIs:
- `GET /api/v1/alerts/events`
- `GET /api/v1/alerts/deliveries`

## Roadmap
Persistent event storage, server-sent realtime events, notification channels, retention controls and richer device/system events remain future work.
