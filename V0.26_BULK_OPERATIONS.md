# SYLVIA v0.26 Beta — Bulk Device Operations

Device groups can now be used as a command target.

## UI

Open `/bulk-operations` to:
- select a device group
- enter a command
- provide JSON payload
- queue the operation
- view per-device queued/rejected counts

## API

`POST /api/v1/groups/:id/bulk-command`

`GET /api/v1/bulk-operations`

The beta records per-device authorization results. The next transport-hardening
step is to dispatch each queued result to the actual REST/MQTT command transport
with idempotency and delivery tracking.
