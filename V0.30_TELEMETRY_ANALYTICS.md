# SYLVIA v0.30 Beta — Telemetry Analytics & Retention

## Analytics

`GET /api/v1/telemetry/analytics`

Parameters:
- `deviceId`
- `streamId`
- `from` (ISO timestamp, optional)
- `to` (ISO timestamp, optional)
- `bucket=1m|5m|15m|1h`

Returns raw samples plus numeric min/max/average/count buckets.

## Retention

`GET /api/v1/telemetry/retention?streamId=temperature`

`PUT /api/v1/telemetry/retention`

```json
{
  "streamId": "temperature",
  "enabled": true,
  "days": 90
}
```

The beta stores policy state in-process. v1.0 should persist policies and run
an actual database cleanup/partition-retention job. Analytics are capped at
5000 returned samples per request in this beta.
