# SYLVIA v0.49 Beta — End-to-End Hardware Hardening

This release freezes major feature work and prepares the complete NodeMCU → MQTT/TLS → SYLVIA → dashboard → command loop for the v0.50 Hardware Beta.

## Added
- Hosted beta configuration preflight (`node scripts/beta-preflight.mjs`)
- Strong secret-length validation
- HTTPS requirement for the public base URL
- TLS warning for non-`mqtts://` hosted brokers
- Node MQTT transport honors TLS and connection-timeout configuration
- ESP8266 SDK no longer silently accepts an insecure TLS fallback
- ESP8266 heartbeat firmware metadata updated to `esp8266-sdk-0.49`
- Release/version metadata updated to `0.49.0-beta.1`

## Hosted preflight
Set the hosted environment variables and run:

```bash
node scripts/beta-preflight.mjs
```

The check intentionally fails when required production credentials are absent or too short.

## Hardware acceptance test
1. Apply database migrations.
2. Configure an `mqtts://` broker and certificate trust.
3. Run the web service and MQTT bridge.
4. Claim/provision one NodeMCU device.
5. Flash `sdk/esp8266/SYLVIA_ESP8266_BASIC`.
6. Confirm heartbeat changes the device to online.
7. Publish a telemetry value and verify it appears in telemetry analytics.
8. Trigger an alert threshold and verify the event/notification pipeline.
9. Send a dashboard command and verify NodeMCU acknowledgement.
10. Disconnect Wi-Fi and confirm offline/stale detection, then reconnect and confirm recovery.

## v0.50 gate
No new major features should be required for the first hardware beta. Remaining work is deployment-specific configuration, real-broker credentials, flashing the user's board, and end-to-end verification.
