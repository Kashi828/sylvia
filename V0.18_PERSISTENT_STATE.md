# SYLVIA v0.18 Beta — Persistent State + Realtime Sync

## Goal
Move SYLVIA from command acknowledgement to authoritative device state synchronization.

## Flow
Dashboard -> command -> device -> hardware -> reportState() -> state store -> SSE -> dashboard

## REST
- `GET /api/v1/devices/state?deviceId=...`
- `POST /api/v1/devices/state`
- `GET /api/v1/devices/state-events?deviceId=...`

## ESP32
```cpp
Sylvia.reportState("relay", true);
Sylvia.reportState("temperature", 27.5);
Sylvia.reportState("mode", "auto");
```

The beta uses an in-process state abstraction so it remains runnable without
Redis or another external realtime service. The abstraction can be replaced
by PostgreSQL/Redis in the production hardening phase.
