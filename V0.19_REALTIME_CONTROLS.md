# SYLVIA v0.19 Beta — Realtime Device Controls

## What changed
The Device Control Center now subscribes to the SYLVIA state event stream.
When firmware reports state, the control panel receives it without a page refresh.

### Realtime flow
Dashboard control → command queue → device → hardware → `reportState()` → SSE → dashboard

### API
- `GET /api/v1/devices/state?deviceId=...` — current authoritative state
- `POST /api/v1/devices/state` — device state report
- `GET /api/v1/devices/state-events?deviceId=...` — realtime SSE stream

This beta keeps the transport contract independent of MQTT so MQTT can be introduced
without changing the dashboard/device application API.
