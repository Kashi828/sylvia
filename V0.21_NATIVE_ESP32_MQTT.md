# SYLVIA v0.21 Beta — Native ESP32 MQTT

The ESP32 can now use the SYLVIA MQTT transport directly.

## Device topics

`SylviaMQTT` subscribes to:

`sylvia/devices/<deviceId>/command`

and publishes retained state to:

`sylvia/devices/<deviceId>/state`

## Arduino dependency

Install the `PubSubClient` Arduino library.

## Example

See:

`examples/esp32-mqtt-native/esp32-mqtt-native.ino`

This is intentionally transport-level SDK support. The SYLVIA application-level
command/state model remains unchanged, allowing REST and MQTT devices to coexist.
