# SYLVIA v0.47 — Hosted NodeMCU Beta

## Goal
Deploy the Next.js dashboard/API and a small long-running MQTT bridge. The bridge is required for hosted/serverless deployments because inbound MQTT subscriptions need a persistent process.

## Recommended beta topology

Browser → SYLVIA Next.js app/API → PostgreSQL
                          ↕
                    MQTT broker (TLS)
                          ↕
                    NodeMCU / ESP8266

For Vercel/serverless hosting, run `workers/mqtt-bridge.mjs` separately (Docker/Render/Railway/Fly.io/etc.). The web app may publish commands to the broker; the bridge forwards inbound device telemetry to the hosted API.

## Required web environment
- `DATABASE_URL`
- `SYLVIA_DEVICE_TOKEN_SECRET` — long random secret
- `SYLVIA_MQTT_BROKER` — preferably `mqtts://...`
- `SYLVIA_MQTT_USERNAME`
- `SYLVIA_MQTT_PASSWORD`
- `SYLVIA_MQTT_CLIENT_ID`
- `SYLVIA_MQTT_TOPIC_PREFIX` (default `sylvia`)
- `SYLVIA_PUBLIC_BASE_URL`
- `SYLVIA_BRIDGE_TOKEN`

## Required bridge environment
- `SYLVIA_MQTT_BROKER`
- `SYLVIA_MQTT_USERNAME`
- `SYLVIA_MQTT_PASSWORD`
- `SYLVIA_MQTT_TOPIC_PREFIX`
- `SYLVIA_PUBLIC_BASE_URL`
- `SYLVIA_BRIDGE_TOKEN`

## Beta smoke test
1. Deploy the web app.
2. Apply database migrations.
3. Deploy the bridge as a long-running worker.
4. Configure an MQTT/TLS broker on port 8883.
5. Provision/claim a NodeMCU device and copy its one-time token.
6. Flash `sdk/esp8266/SYLVIA_ESP8266_BASIC/SYLVIA_ESP8266_BASIC.ino` with the broker hostname, port, CA certificate, device ID and token.
7. Confirm `/api/v1/health` reports database and MQTT configuration.
8. Confirm the device becomes online after heartbeat.
9. Publish a telemetry value from the NodeMCU and verify it appears in telemetry/analytics.
10. Send `identify`, `sync`, or another supported command from the dashboard and verify the NodeMCU acknowledges it.

## Security
Do not use `BearSSL::setInsecure()` for the hosted beta. Supply a CA certificate. Keep device tokens and bridge secrets out of source control. Use TLS MQTT and rotate credentials if exposed.
