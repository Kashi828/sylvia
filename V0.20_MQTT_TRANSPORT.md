# SYLVIA v0.20 Beta — MQTT Device Transport

SYLVIA now has an MQTT transport bridge for the existing command/state contracts.

## Topics

- `sylvia/devices/<deviceId>/command`
- `sylvia/devices/<deviceId>/state`

The prefix can be changed with `SYLVIA_MQTT_TOPIC_PREFIX`.

## API

- `GET /api/v1/mqtt/status`
- `POST /api/v1/mqtt/publish`

The publish endpoint requires the device bearer token.

## Environment

```env
SYLVIA_MQTT_BROKER=mqtt://localhost:1883
SYLVIA_MQTT_USERNAME=
SYLVIA_MQTT_PASSWORD=
SYLVIA_MQTT_CLIENT_ID=sylvia-cloud
SYLVIA_MQTT_TOPIC_PREFIX=sylvia
```

MQTT is a transport layer, not a replacement for the SYLVIA application API.
The same device command/state model can continue to work over REST or MQTT.
