# SYLVIA v0.43 Beta — NodeMCU / ESP8266 SDK

First-class ESP8266/NodeMCU MQTT support for the hosted hardware path.

`NodeMCU → Wi-Fi → MQTT/TLS → SYLVIA → telemetry/state/commands`

API: `Sylvia.begin()`, `Sylvia.run()`, `Sylvia.virtualWrite()`, `Sylvia.reportState()`, `Sylvia.onCommand()`.

MQTT topics:
- `sylvia/devices/{deviceId}/telemetry`
- `sylvia/devices/{deviceId}/state`
- `sylvia/devices/{deviceId}/command`
- `sylvia/devices/{deviceId}/heartbeat`

Port 8883 requires a CA certificate. The SDK intentionally refuses to silently downgrade hosted TLS to insecure MQTT.
