# SYLVIA v0.25 Beta — Device Groups

Groups provide a fleet organization layer above individual devices.

## UI

Open `/groups`.

Create groups with a name and optional description. Each group tracks its
device IDs and can be populated through the group API.

## API

- `GET /api/v1/groups`
- `POST /api/v1/groups`
- `GET /api/v1/groups/:id/devices`
- `POST /api/v1/groups/:id/devices`
- `PUT /api/v1/groups/:id/devices`

The beta uses an in-process registry. Production v1.0 will persist groups,
enforce workspace membership/RBAC, and validate every device belongs to the
current project before bulk actions.
