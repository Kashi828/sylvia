# SYLVIA v0.17 Beta — Device State Synchronization

Closes the v0.16 command loop: delivered commands can be acknowledged, and device-authoritative datastream state can be reported back to SYLVIA.

### Flow
Dashboard → command queue → device SDK → callback → ACK → event/state update.

### APIs
- `GET /api/v1/devices/commands/pending`
- `POST /api/v1/devices/commands/ack`
- `POST /api/v1/devices/{id}/state`
- `POST /api/v1/devices/command` SDK self-command compatibility route

### SDK
`Sylvia.reportState(streamId, value)` reports device-authoritative state using the virtual-channel contract.
