# SYLVIA v0.46 — Cloud-to-NodeMCU Commands

SYLVIA v0.46 closes the cloud-to-device control loop for the ESP8266/NodeMCU SDK.

## Flow

1. Dashboard/API authenticates with the device credential.
2. SYLVIA creates a command ID and records it as in-flight.
3. If MQTT is configured, SYLVIA publishes to `sylvia/devices/{deviceId}/command`.
4. NodeMCU receives `{commandId, command, payload}` and invokes `onCommand`.
5. NodeMCU publishes `{commandId, token, result}` to `sylvia/devices/{deviceId}/command-ack`.
6. SYLVIA validates the device token and marks the command acknowledged.

## Fallback

If MQTT is not configured or dispatch fails, the command remains available through the existing pending-command polling endpoint.

## Hosted beta requirement

Use MQTT over TLS (normally port 8883) with a CA certificate on the NodeMCU. Do not use the SDK development `setInsecure()` path for a public deployment.
