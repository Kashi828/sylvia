# SYLVIA v0.23 Beta — Device Registry & Fleet Management

SYLVIA now has a fleet-level device registry foundation.

## Lifecycle

- `provisioning`
- `online`
- `offline`
- `disabled`

## Endpoints

- `GET /api/v1/fleet`
- `POST /api/v1/fleet`
- `POST /api/v1/fleet/lifecycle`
- `POST /api/v1/fleet/presence`

Devices become `offline` after 90 seconds without a presence update in the
current beta. Disabled devices remain disabled.

## Device presence

Authenticated devices can report:

```json
{
  "deviceId": "device-01",
  "firmware": "0.23.0",
  "transport": "mqtt"
}
```

The registry is intentionally isolated behind an interface so the in-memory
beta implementation can later be replaced by PostgreSQL/Redis-backed fleet
storage.
