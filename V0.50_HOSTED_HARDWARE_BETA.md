# SYLVIA v0.50 Beta — Hosted Hardware Beta

v0.50 is the formal hosted hardware-beta milestone. It combines the cloud, MQTT/TLS, device authentication, NodeMCU SDK, telemetry, and command foundations into one controlled acceptance path.

## Hardware Test Center

Open `/beta` after deployment. Run the hosted preflight, then use a physical NodeMCU/ESP8266 with the SDK under `sdk/esp8266/Sylvia`.

## Acceptance sequence

1. Deploy the web application and configure PostgreSQL.
2. Configure an MQTT broker with TLS (normally port 8883).
3. Set the hosted device-auth and bridge secrets.
4. Provision/claim a device and keep its token private.
5. Flash the ESP8266 example with Wi-Fi, broker hostname, port, and CA certificate.
6. Verify device presence in Fleet.
7. Publish telemetry and verify it in Telemetry/Analytics.
8. Trigger an alert and verify the Event/Notification pipeline.
9. Send a cloud command and verify the NodeMCU command acknowledgement.
10. Disconnect/reconnect the board and verify lifecycle/last-seen recovery.

## Security gate

Do not use insecure MQTT/TLS bypasses for the public beta. The ESP8266 SDK requires a CA PEM for its TLS client. Keep `SYLVIA_DEVICE_TOKEN_SECRET` and `SYLVIA_BRIDGE_TOKEN` in the hosting environment and never commit them.

## Scope

v0.50 is a hardware beta milestone. It does not mean the platform has reached production SLA, multi-region scaling, or stable v1.0 status.
