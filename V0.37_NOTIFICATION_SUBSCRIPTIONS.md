# SYLVIA v0.37 Beta — User & Project Notification Subscriptions

v0.37 adds a routing foundation for multi-user, multi-project notification delivery.

## Included
- Subscription records scoped by `userId` and `projectId`.
- Filters for all events, telemetry alerts, or webhook deliveries.
- Severity filters: all, info, warning, critical, success, error.
- Enable/pause and delete controls.
- PostgreSQL migration `005_notification_subscriptions.sql`.
- In-memory fallback for local/demo mode.
- Dashboard Subscription workspace.
- REST API at `/api/v1/notifications/subscriptions`.

## API
`GET /api/v1/notifications/subscriptions?userId=usr_owner&projectId=sylvia-local-workspace`

`POST /api/v1/notifications/subscriptions` with `{ "kind":"alert", "severity":"critical" }`

`DELETE /api/v1/notifications/subscriptions?id=<subscriptionId>`

This beta establishes routing metadata. Full authenticated user/project enforcement and external delivery channels remain later hardening work.
