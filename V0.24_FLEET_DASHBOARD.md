# SYLVIA v0.24 Beta — Fleet Dashboard

The v0.24 beta adds a dedicated `/fleet` dashboard over the v0.23 device
registry.

## UI

- Total device count
- Online/offline/provisioning/disabled counts
- Clickable status filters
- Device ID and name
- Transport
- Firmware
- Last-seen timestamp
- Manual refresh
- Automatic 15-second refresh

## API

The UI consumes `GET /api/v1/fleet`.

This beta keeps the registry implementation in-process. Persistent multi-user
fleet storage remains part of the production-hardening work.
