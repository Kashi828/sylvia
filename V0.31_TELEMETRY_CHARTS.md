# SYLVIA v0.31 Beta — Telemetry Analytics UI

Open `/telemetry/analytics`.

Features:
- Device and stream selectors
- 1h / 6h / 24h / 7d time ranges
- 1m / 5m / 15m / 1h aggregation
- Sample count and min/average/max metrics
- Aggregated trend visualization
- Recent bucket table
- Manual refresh

The page consumes the v0.30 analytics endpoint and remains independent of a
specific charting library so the beta stays lightweight.
