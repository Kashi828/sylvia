# SYLVIA v0.12 Beta — production connectivity hardening

This beta focuses on the production path between a device and SYLVIA's cloud API.

## Device telemetry

`POST /api/v1/devices/:id/telemetry`

Headers:
`Authorization: Bearer <device-token>`
`Content-Type: application/json`

Body:
```json
{"streamId":1,"value":26.4}
```

## Batch telemetry

`POST /api/v1/telemetry/batch`

```json
{"items":[{"deviceId":1,"streamId":1,"value":26.4},{"deviceId":1,"streamId":2,"value":86}]}
```

## Device commands

`POST /api/v1/devices/:id/command`

Supported commands: `restart`, `sync`, `identify`, `set_online`, `set_offline`.

## API protection

The routes include basic in-process rate limiting and validate that a device token can only write to streams belonging to that device.

For production deployment, replace the in-memory limiter/store with a shared Redis/PostgreSQL-backed implementation before horizontal scaling.
